# Brouillon de SRS :

## Interface :
pouvoir louer en moins de 5 minutes (si a déjà loué précédemment)
on doit pouvoir créer un compte sur la machine
pouvoir recharger la carte depuis la machine
un abonné doit pouvoir consulter sa wishlist et la modifier
pouvoir activer une carte d'abonnement
avoir la possibilité de déclarer un dvd abimé, et être remboursé (le dvd est remis dans la machine, le remboursement a lieu après vérification du dvd par technicien)
le client peut voir son historique sur 1 an
pas besoins d'accessibilité
pas d'accès sur l'interface pour le technicien ou le shop owner
un client peut voir la wishlist globale
pas de downvote
pour créer un compte :
	- nom prénom type de public (famille, adulte, enfant...)
	- pouvoir refuser de louer certains films
pour louer :
- mettre la carte, voir les meilleurs films du moment, filtres de recherches, infos du film (synopsis…), bouton louer -> vérification, pouvoir retirer la carte à n'importe quel moment, toutes les opérations sont annulées)
- un film déjà loué reste visible, mais afficher clairement qu'il est loué
l'interface doit pouvoir être flexible pour être modifiée a distance, sans besoins de toucher au code
avoir un retour (pourcentage) de l'état en cours, si des hauts parleurs sont présents, les utiliser
un non-abonné peut voir la liste exhaustive doit être visible des dvd
aucune info au dehors de la carte de crédits pour louer (garder en mémoire l'empreinte de la carte pour être capable de dire si un dvd est déjà loué pour cette carte)
un abonné peut avoir des suggestions basées sur ce qu'il a loué précédemment (peut être un feedback)
un client doit pouvoir vider/aliment son solde depuis la machine
le montant minimum pour aliment le solde est de 10€
a la création du compte, il faut fournir 15€ minimum pour alimenter la carte
## Autres :
Faire une wishlist (pas de taille limite) (uniquement pour les abonnées)
n'importe qui peut louer un film (pas besoins de suscription)
uniquement le code de la machine
mise à jour du logiciel via internet
le logiciel doit permettre de modifier la liste des films disponibles
un dvd doit être rendu dans le même machine
Détecter le dvd qui est remis
un seul slot pour louer/rendre le dvd
deux lecteurs différents pour carte crédit/carte de souscription
un abonné ne peut pas payer avec sa carte de crédit, uniquement sa carte abonnée
quand un dvd est ajouté par un technicien, elle le scan est l'ajoute automatiquement dans sa base de donnée
4€ par film par abonné, 5€ si non abonné
un technicien vient voir la machine tous les mois
100 dvd max dans la machine
un qr code permet de regarder un film dématérialisé, il est désactivé au bout de 12h
limite d'emprunt 24h (12h si qr code)
on peut louer max un dvd si pas abonné, 3 sinon
ajouter une majoration si dvd est rendu en retard
on paye au moment où on retire le dvd
un même exemplaire peut être présent plusieurs fois dans une même machine
le client ne peut jamais être bloqué pour rendre
le technicien peut retirer des dvd si le nombre virtuel dépasse 100
avoir un historique des transactions sur 1 an (doit pouvoir être visible à distance (via puce 4g))
garder en mémoire la carte de crédit tant qu'un film n'a pas été rendu
si le mauvais dvd est rendu, il est refusé
l'entreprise doit pouvoir voir a distance la liste des dvd les plus demandés dans l'ordre croissant
si plus d'argent sur la carte abonné en cas de retard, prélevé sur sa carte bancaire
la majoration de retard doit pouvoir être modifiée par l'entreprise
on doit pouvoir voir l'état de la machine à distance (nombre loué, nombre dans...)
proposer plusieurs langues pour l'user
on remet à 0 les votes quand un dvd de la wishlist est ajouté
minimiser le besoin d'accès à internet (garder un max d'infos en local)
si la machine détecte un problème hardware, on doit informer l'entreprise
la base d'infos doit être stockée dans la machine
pouvoir mettre a jour la machine sans interrompre son fonctionnement
le qr code doit être imprimé physiquement
