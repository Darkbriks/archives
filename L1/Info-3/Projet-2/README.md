# Projet 2 Web - INFO 3 (L1)

Ce projet a été réalisé en binome dans le cadre de l'UE INFO 3 (web) de la L1 informatique à l'ULCO.

## Objectif

L'objectif de ce projet était de réaliser un site web de type "site vitrine" pour un produit fictif au choix.

Le site devait au minimum contenir les éléments suivants :
- Une page d'accueil
- Une page de présentation du produit
- Une page de contact comporant un formulaire de contact (le formulaire n'a pas besoin d'être fonctionnel)
- Un carrousel d'images, avec la possibilité de rajouter des images via un lien
- Un menu de navigation
- Un style cohérent sur l'ensemble du site
- Une légère responsivité (le site doit être consultable sur plusieurs tailles d'écrans d'ordinateurs, mais pas sur mobile)
- Des fonctionnalités JavaScript
